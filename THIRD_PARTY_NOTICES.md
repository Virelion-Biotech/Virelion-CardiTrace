# Third-party inspiration and licensing

CardiTrace's provenance architecture was informed by public open-source projects including:

- ORNL/flowcept — MIT License, copyright Oak Ridge National Laboratory (2022).
- RI-SE/dataprov — MIT License, copyright Fredrik Warg (2025).
- DVC — Apache License 2.0.

The current CardiTrace implementation is an independent, dependency-free implementation of compatible concepts and does not vendor source files from those projects. Where future source-level reuse is introduced, the exact upstream file, version/commit, license, and required notices must be recorded here before merge.

Key adopted concepts include content-addressed artifacts, execution provenance, semantic entity/activity/agent relationships, dataset manifests, reproducibility identities, lineage traversal, and compact provenance cards.
